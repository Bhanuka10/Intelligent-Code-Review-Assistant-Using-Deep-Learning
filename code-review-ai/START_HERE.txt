❓ FREQUENTLY ASKED QUESTIONS:

  Q: Is my code stored anywhere?
  A: No! Code is only analyzed, not stored or sent anywhere.

  Q: How accurate is the model?
  A: ~56% accuracy. Use as first-pass filter, always review manually.

  Q: What if my code is not in C/C++?
  A: Model works on Python, Java, JS, Go, Rust with variable accuracy.

  Q: Can I use this offline?
  A: Yes! After first run when model is cached locally.

  Q: How do I improve accuracy?
  A: Fine-tune on your own labeled dataset using training notebook.

  Q: Why is first run slow?
  A: First run downloads 500MB model from Hugging Face (cached after).

  Q: Can I customize the colors?
  A: Yes! Edit Static/Style.css CSS variables.

  Q: How do I deploy to production?
  A: See ARCHITECTURE.md → Deployment Scenarios section.

🔧 TROUBLESHOOTING:

  Problem: Port 7860 already in use
  Solution: Change port in app.py or kill process using port

  Problem: Model loading is slow
  Solution: Normal on first run. Subsequent runs use cached model.

  Problem: High latency during analysis
  Solution: Normal (0.8-1.2s). Install PyTorch CUDA for GPU speedup.

  Problem: Out of memory errors
  Solution: Reduce batch_size in model_interface.py

  Problem: Page not loading
  Solution: Check terminal for error messages. Port might be blocked.

📊 UNDERSTANDING RESULTS:

  Prediction Badges:
  🚨 DEFECTIVE (Red)    = Code contains potential issues
  ✓ CLEAN (Green)       = Code appears safe

  Confidence Levels:
  90-100%  = Very High Confidence
  70-89%   = High Confidence
  50-69%   = Moderate Confidence
  <50%     = Low Confidence (manual review recommended)

  Metrics:
  Accuracy   = % of correct predictions overall
  Precision  = % of flagged defects that are real
  Recall     = % of actual defects that were detected
  F1 Score   = Balance between precision and recall
